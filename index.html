01 / Why01 / Warum

A model always produces something.

Ein Modell liefert immer etwas.

That is the problem. Asked about a brand it holds no approved truth about, a language model answers from the average of everything it has read. The result is fluent, plausible and quietly wrong.

Genau das ist das Problem. Fragt man ein Sprachmodell zu einer Marke, über die es keine freigegebene Wahrheit hat, antwortet es aus dem Durchschnitt von allem, was es gelesen hat. Das Ergebnis ist flüssig, plausibel und still falsch.

A brandbook explains.

Ein Brandbook erklärt.

A prompt asks.

Ein Prompt bittet.

OBDS defines what applies.

OBDS legt fest, was gilt.

Brandbooks are written for people and stay useful. A prompt can carry guidance but cannot guarantee that it was followed. OBDS is the layer underneath: governed brand truth a system can resolve, check and record.

Brandbooks sind für Menschen geschrieben und bleiben wertvoll. Ein Prompt kann Orientierung transportieren, aber nicht garantieren, dass sie befolgt wurde. OBDS liegt darunter: freigegebene Markenwahrheit, die ein System auflösen, prüfen und protokollieren kann.

03 / Decide03 / Entscheiden

Decide, or say honestly that you cannot.

Entscheiden. Oder ehrlich sagen, dass es nicht geht.

Brand truth is stored as scoped elements: facts, rules, context and qualitative boundaries. Each one carries a knowledge state, a scope, its sources and a machine-readable value contract. For a given task the compiler resolves which element applies, or it fails.

Markenwahrheit liegt als gescopte Elemente vor: Fakten, Rules, Kontext und qualitative Grenzen. Jedes Element trägt einen Knowledge State, einen Scope, seine Quellen und einen maschinenlesbaren Value Contract. Für eine Aufgabe löst der Compiler auf, welches Element gilt. Oder er bricht ab.

What is true?

Was ist wahr?

What applies here?

Was gilt hier?

What conflicts?

Was widerspricht sich?

What is unknown?

Was ist unbekannt?

May the system proceed?

Darf das System weitermachen?

Can it prove why?

Kann es belegen, warum?

Retrieval answers the first question. OBDS answers all six, and keeps the answer. That is the difference between looking something up and making a governed decision.

Retrieval beantwortet die erste Frage. OBDS beantwortet alle sechs und behält die Antwort. Das ist der Unterschied zwischen Nachschlagen und einer freigegebenen Entscheidung.

defined
An applicable value exists and may be used when the scope matches.
Ein anwendbarer Wert existiert und darf bei passendem Scope verwendet werden.
unknown
A value is expected but not known. Dependent use is blocked or escalated. Never guessed.
Ein Wert wird erwartet, ist aber nicht bekannt. Abhängige Nutzung wird blockiert oder eskaliert. Nie geraten.
not_defined
The brand deliberately defines no value. The system returns that, it does not infer one.
Die Marke legt bewusst keinen Wert fest. Das System gibt genau das zurück und leitet nichts ab.
not_applicable
The element does not apply here. It is omitted with an explanation.
Das Element trifft hier nicht zu. Es entfällt mit Begründung.

Four states, and only these four. Brand States describe knowledge status, nothing else. Workflow states such as draft or pending review are not brand states.

Vier Zustände, und nur diese vier. Brand States beschreiben ausschließlich den Wissensstand. Workflow-Zustände wie Draft oder Pending Review sind keine Brand States.

obligation: prohibit

A prohibition is not a knowledge state. It is an explicit RULE with its own scope, its declared enforcement and its declared validation method. That is the only path a brand has to forbid something, and it is the reason a block can be traced back to a decision instead of to a missing value.

Ein Verbot ist kein Wissenszustand. Es ist eine explizite RULE mit eigenem Scope, deklariertem Enforcement und deklarierter Prüfmethode. Das ist der einzige Weg, auf dem eine Marke etwas verbieten kann, und der Grund, warum sich eine Blockade auf eine Entscheidung zurückführen lässt und nicht auf einen fehlenden Wert.

subject
The semantic key. Elements that compete for the same meaning declare the same subject. Similar names or values never imply it.
Der semantische Schlüssel. Elemente, die um dieselbe Bedeutung konkurrieren, deklarieren dasselbe Subject. Ähnliche Namen oder Werte reichen nie aus.
scope
Market, channel, product, campaign, audience. A stricter scope wins inside its own scope, and nowhere else.
Markt, Kanal, Produkt, Kampagne, Zielgruppe. Der engere Scope gewinnt innerhalb seines Scopes, sonst nirgends.
conflict
Two equally specific candidates for one subject are a hard failure. File order, array order and timestamps are never precedence.
Zwei gleich spezifische Kandidaten für ein Subject sind ein harter Fehler. Dateireihenfolge, Array-Reihenfolge und Zeitstempel sind nie Präzedenz.
asOf
Every build declares the moment it is built for. Validity is evaluated against that timestamp, never against the compiler clock.
Jeder Build deklariert den Zeitpunkt, für den er gilt. Gültigkeit wird gegen diesen Zeitstempel geprüft, nie gegen die Systemuhr.

The point is not that a model understands the brand. The point is that a supported decision exists, or provably does not.

Es geht nicht darum, dass ein Modell die Marke versteht. Es geht darum, dass eine belegte Entscheidung existiert. Oder nachweisbar nicht.

04 / Distinctive04 / Unterscheidbar

A brand is easier to hold by its edges.

Eine Marke lässt sich an ihren Kanten besser fassen.

Qualitative direction usually dies as a list of adjectives that every brand could claim. A Semantic Boundary keeps it structured and machine-readable: one subject, one quality, what it is, what it is not, and the trade-off the brand has already settled.

Qualitative Richtung stirbt meist als Adjektivliste, die jede Marke für sich beanspruchen könnte. Eine Semantic Boundary hält sie strukturiert und maschinenlesbar: ein Subject, eine Quality, was sie ist, was sie nicht ist, und der Trade-off, den die Marke bereits entschieden hat.

guidance != compliance

A missing positive trait is not a violation. Strong evidence of an is-not trait may support a material conflict and send the result to review. Only a separate applicable RULE turns that conflict into a compliance violation. Keeping the two apart is what stops qualitative direction from silently becoming a blocking checklist.

Ein fehlendes positives Merkmal ist keine Verletzung. Starke Evidenz für ein Is-not-Merkmal kann einen Material Conflict stützen und das Ergebnis in die Prüfung geben. Erst eine separate anwendbare RULE macht daraus eine Compliance-Verletzung. Diese Trennung verhindert, dass qualitative Richtung still zur blockierenden Checkliste wird.

Not just what the brand is. What it is not.

Nicht nur, was die Marke ist. Auch, was sie nicht ist.

The same contract holds for voice, photography, art direction, composition and product depiction. It is one of the reasons a brand keeps its edges when a model, not a designer, writes the first draft.

Derselbe Contract gilt für Voice, Fotografie, Art Direction, Komposition und Produktdarstellung. Er ist einer der Gründe, warum eine Marke ihre Kanten behält, wenn ein Modell und kein Designer den ersten Entwurf schreibt.

05 / Compile05 / Kompilieren

Not the archive. The exact truth for this task.

Nicht das Archiv. Genau die Wahrheit für diese Aufgabe.

Sources are consolidated once into an approved Brand Manifest. A Build Plan names the target and the moment in time. The compiler resolves scope, verifies that required truth exists and emits one Compiled Brand Context. Runtime builds the model input from that artefact and from nothing else.

Quellen werden einmal zu einem freigegebenen Brand Manifest zusammengeführt. Ein Build Plan benennt das Target und den Zeitpunkt. Der Compiler löst den Scope auf, prüft, ob die geforderte Wahrheit vorhanden ist, und erzeugt einen Compiled Brand Context. Die Runtime baut den Model Input aus genau diesem Artefakt und aus nichts anderem.

07 / Prove07 / Nachweisen

Months later, you can still show why.

Monate später lässt sich noch zeigen, warum.

Which approved truth was used. Which rules applied. Which context was assembled. Whether a model was called at all. Why the result was released, blocked or sent to approval. The record is a by-product of the run, not a report written afterwards.

Welche freigegebene Wahrheit verwendet wurde. Welche Rules galten. Welcher Kontext assembliert wurde. Ob überhaupt ein Modell aufgerufen wurde. Warum das Ergebnis freigegeben, blockiert oder zur Freigabe geleitet wurde. Der Nachweis fällt im Lauf an und wird nicht nachträglich geschrieben.

Canonical hashes prove the approved bytes

Canonical Hashes beweisen die freigegebenen Bytes

One serialisation contract across languages. Duplicate keys are rejected, integers that cannot round-trip are rejected, and 1 and 1.0 hash identically.

Ein Serialisierungs-Contract über Sprachgrenzen hinweg. Doppelte Keys werden abgelehnt, Integer ohne Roundtrip werden abgelehnt, und 1 und 1.0 hashen identisch.

Value contracts pin the machine meaning

Value Contracts fixieren die maschinelle Bedeutung

A structured value binds a shape hash, a schema reference, a schema hash and an optional deterministic validator. Structure and semantics are pinned separately.

Ein strukturierter Wert bindet Shape-Hash, Schema-Referenz, Schema-Hash und optional einen deterministischen Validator. Struktur und Semantik werden getrennt fixiert.

Changes are shown before approval

Änderungen werden vor der Freigabe gezeigt

A deterministic change report separates added, changed and removed elements and keeps value, scope, state, validity and contract changes apart.

Ein deterministischer Change Report trennt hinzugefügte, geänderte und entfernte Elemente und hält Wert-, Scope-, State-, Gültigkeits- und Contract-Änderungen auseinander.

Every runtime attempt is recorded

Jeder Runtime-Versuch wird protokolliert

Target, artefact hash, assembly hash, model input hash, check results, whether a model was called, and one decision: released, blocked, approval required or failed.

Target, Artefakt-Hash, Assembly-Hash, Model-Input-Hash, Check-Ergebnisse, ob ein Modell aufgerufen wurde, und eine Entscheidung: freigegeben, blockiert, Freigabe erforderlich oder fehlgeschlagen.

Rendered output is measured, not judged

Gerendertes wird gemessen, nicht bewertet

Geometry evidence carries the boxes that were actually produced. A composition claim fails if a never-omit role is missing, rather than passing vacuously.

Geometry Evidence trägt die tatsächlich erzeugten Boxen. Ein Composition-Claim schlägt fehl, wenn eine Never-Omit-Role fehlt, statt leer durchzugehen.

Conformance is tested, not declared

Conformance wird getestet, nicht behauptet

A tool may say it uses OBDS concepts. It may only say OBDS conformant once the official suite for that exact version and profile is green and the result is retained.

Ein Tool darf sagen, dass es OBDS-Konzepte nutzt. OBDS-konform darf es sich erst nennen, wenn die offizielle Suite für genau diese Version und dieses Profil grün ist und das Ergebnis aufbewahrt wird.

Ein Decision Record ist auditierbare Systemevidenz. Er ist kein kryptografischer Beweis, dass anderswo kein weiterer, nicht instrumentierter Aufruf stattgefunden hat.
