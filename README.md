# Open Brand Definition website

Static one-page website for `openbranddefinition.org`.

## Files

- `index.html`: complete bilingual site, CSS and JavaScript included
- `favicon.svg`: site icon
- `robots.txt`: search engine rules
- `sitemap.xml`: homepage sitemap
- `CNAME`: GitHub Pages custom domain file

## Deployment

Upload all files to the public root of the domain. No build process is required.

The page uses no external fonts, frameworks, analytics or tracking scripts.

## Before publishing

- Confirm the company and legal notice details.
- Confirm whether the planned CC BY 4.0 and Apache 2.0 licensing should remain visible.
- Configure HTTPS and the preferred `www` redirect at the hosting provider.
